# Supporting tools

These utilities support research, validation, and no-write quality analysis around the canonical scorer.

- `icp_quality_agent/`: preflight and post-retrieval Account-quality overlays.
- `vertical_resolution/`: candidate website and Virginia registry validation.
- `alta/`: ALTA matching and coverage analysis. Licensed source exports are not included.
- `analysis/`: calibration, backtest, population-audit, variance, and customer-history utilities.

Several tools default to historical local artifact paths for reproducibility. Supply explicit input/output arguments in a clean environment. Do not place private inputs or generated outputs in Git.
